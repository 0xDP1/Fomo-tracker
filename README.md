# FOMO Tracker

A static web app (no build step, no backend) that does four things:

- watches the balance of your FOMO (Solana) wallet
- logs and syncs your trades
- shows performance stats
- suggests how much to put into each trade.

## Run it

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000   # then visit http://localhost:8000
```

Type a **FOMO username** in the box at the top and press **Go**:

- **First time:** the app asks for that user's Solana wallet address, then remembers it. FOMO doesn't publish usernames or the wallets behind them, so this one-time step is needed. Your own address is on the deposit/receive screen in the FOMO app.
- **After that:** typing the username loads its balance and stats straight away. Bookmark `index.html?user=<username>` to jump straight to it.
- **Several users:** each username keeps its own trades and balance history, so you can track a few traders and switch between them.
- **Address instead:** pasting a Solana address into the box works too.

Optional settings:

- **Helius API key** (free at helius.dev). It turns on **Sync from wallet**, which pulls your recent swaps and turns them into trades automatically. It also gives you a faster RPC than the public one. With a key set, the first load of a new username syncs automatically.
- **FOMO API (fomoapi.io) key.** Paste a `fapi_…` key into **Lookup API key** in Settings and save. This turns on **all-chain mode**, covering Solana, Base, BNB, Ethereum, Monad and Robinhood Chain:
  - usernames are looked up automatically
  - the dashboard shows your FOMO balance across all chains, a per-chain breakdown, and FOMO's own PnL for 24h, 7d, 30d and all time
  - **Sync trades** pulls your positions from every chain
  - all amounts are in USD, and Stats adds a by-chain table.

  If fomoapi.io can't be reached, the app falls back to the Solana wallet.

  fomoapi.io bills about 250 credits per call (free plan: 250,000 a month). To stay inside that, the app refreshes FOMO data at most every 10 minutes, syncs trades every 15, refreshes Following every 10 minutes only while the Home is open, and skips the paging probe for a day once it knows none works. Each sync keeps every trade seen before, so your history builds up over time even though fomoapi.io only returns the newest page. Settings shows this month's calls and credits. If the credits run out (HTTP 402), the app says so and pauses fomoapi.io calls for an hour; tapping Refresh or saving Settings tries again straight away.
- **Anthropic API key** (optional). Enables the AI write-up on the Check tab. Calls go straight from your browser to Anthropic; the key is stored only in this browser.
- **Username lookup API.** Some unofficial third-party services map FOMO usernames to wallets. Put the endpoint in Settings (use `{handle}` where the username goes), plus its API key if it needs one. Unknown usernames are then resolved automatically: the app takes the Solana address from the response.

Everything stays in your browser's localStorage. Known bugs and their fixes are listed in `docs/BUGS.md`. Use **Export JSON backup** to keep a copy (it leaves your API keys out). To move the app to another device or browser (it works on a computer too: https://0xdp1.github.io/Fomo-tracker/), **Export keys** saves your API keys to a file locked with a password you choose (AES-256, done in your browser, nothing sent anywhere), and **Import keys** on the other device fills them in with the same password; there is no password recovery. Tick **Show password** to check what you typed.

**Layout:** each tab leads with its main job: your balance and performance on the Home (4 key stats, **More stats** for the rest), the contract box on Check, Insights on Stats. Bigger panels (Call queue, Market pulse, Scanner, and the Stats groups Calendar, Timing, Coins & setups, Costs & lessons, Charts) fold away and remember whether you left them open; Market pulse and Scanner show a one-line summary when folded. Empty panels stay hidden until they have something to show.

**On a phone:** open the site in Safari, then Share → **Add to Home Screen**. It runs full-screen with its own icon and a bottom tab bar, and updates itself: when a new version is published it installs it on open or when you come back after 2+ minutes away (with a short "Updated to" note), unless you're typing, a check is running or an AI request is in flight; then, and while you're using it, it offers a one-tap **Update now** bar instead. Rarely used settings (Solana wallet, Helius, custom lookup providers) are under **Advanced** on the Settings tab.

## Features

| Tab | What it does |
| --- | --- |
| **Home** | **Find a trader:** type a FOMO handle or fomo.family link, or upload a profile screenshot (read by Claude with your Anthropic key), to see their win rate and trading style from their latest closed trades: hold style (scalper, day trader, swing trader, holder), activity, win profile (lottery hunter, quick profit taker, balanced), average size and main chain. **Follow** adds them to Following. SOL balance, token holdings priced in USD (Jupiter), total portfolio value, balance-history chart, auto-refresh, and headline stats with the equity curve and recent trades. **Following:** add FOMO handles (needs the fomoapi.io key) to see their latest buys and sells across chains in one feed, with size, realized PnL on sells, and a **Check** button that opens the token on the Check tab; it refreshes every 2 minutes while the page is open, up to 10 traders. |
| **Layout** | Tabs: Home (wallet, performance, Recent trades with **Sync trades**, open positions, traders), Check (one coin: info, verdict and findings first, then each deep check as a folded row with its headline; red flags open by themselves; **Open all / Close all**; Plan & watch folded), **Calls** (Call queue, Market pulse, Scanner), Stats (with the **Trade log** folded at the bottom), Sizing, Settings (trades CSV import/export under Data). |
| **Check / Calls** | **Call queue** (Calls tab): contract addresses posted in a Discord channel, from four places: pasted messages (**Paste calls** reads the clipboard), a screenshot read by Claude with your Anthropic key, a `?calls=<text>` link (for an iPhone share-sheet Shortcut), or the **Discord feed**, a small Cloudflare Worker you run on your own account that reads up to 10 channels only when the app is open (the app asks every 15 seconds while the Calls tab is open, every minute otherwise; the Worker saves to storage at most once a minute) (it catches up on anything posted while you were away, up to 500 messages per channel, and a **Pause feed** switch stops it) (`CHANNEL_ID` takes `id:label` entries separated by commas; each coin row shows the channels it was posted in) (setup in [`worker/README.md`](worker/README.md); the Discord token stays in Cloudflare, never in the app; using your account token breaks Discord's terms and can get the account banned). Every Solana and 0x address is looked up on DexScreener; coins launched within your window (15 min, 30 min, 1 h, 6 h, 24 h default, 3 days; a **Called within** filter of 15 min, 30 min or 1 h also keeps only coins the channels first posted that recently) get the rug and holder check (best 10 per batch) and are ranked safest and newest first with age, market cap, liquidity, verdict, top warning, mentions, the first caller with their medal and 30-day win rate (kept up to date every time they appear in an alert), the market cap at the call on its own bold line (the alert's price, else the price at the call from 5-minute candles, else "first seen at $X, N min after the call") and how far it has moved since, the channels it was posted in, the shortened contract address with a **Copy** button, and **Check**. Alert bots' own snapshot (age, market cap, liquidity, holders, top 5 wallets) replaces DexScreener lookups, only the best 10 coins get the rug check, and channel chips plus minimum liquidity and caller win-rate filters keep the list short. **Recent calls:** the last 50 calls are always listed whatever the filters (with the market cap at the call, now and the peak since, and why one is hidden from the queue), kept past the 3-day cleanup; while the app is open their prices are read every minute and the first time a call reaches 2× and 4× you get a banner, a vibration and (if allowed) a phone notification; a stat line at the top shows the last calls' win rate (reached 1.5×), 2× hits, best and median peak, per group and per source. The peak also comes from GeckoTerminal's 5-minute candles since the call (10 coins a minute, each every 10 minutes), so a pump while the app was closed still counts, with a "while you were away" alert. **Sort** the list by Newest, Gain now or Peak (tap again to flip the order) and filter it with **Min gain** chips (Any, +0%, +50%, 2×, 4×, Losers); the choice is remembered. **Call lessons:** every call's facts at the moment it was called (age, market cap, liquidity, volume, holders, bundled %, caller, Strength, and for checked coins the rug score, top wallets and the SOL in them) are kept with its true outcome from GeckoTerminal's 5-minute candles 1 h and 4 h later, also for hours the app was closed: **runner** (2× within 4 h, fast within 1 h), **dead** (under 0.3× at 4 h) or flat. A table shows which facts separate the runners from the rest, **Read the patterns** has Claude Haiku explain them in plain words (about 1¢, your Anthropic key), and after 30 runners new calls get an **n/5 like runners** pill with its own Signal scorecard row; the last 300 calls are kept on your phone. Calls priced within 30 minutes of being posted are re-priced 1, 6 and 24 hours later, and a **Callers** table shows each poster's wins and average return, crediting the first person to post a coin. **Alerts while the app is closed:** with a Telegram bot token on the Worker (`worker/README.md`), the Worker prices the last day's calls every 5 minutes and messages you on 2×, 4× and big moves using the same rules, and Recent calls pick up the peaks it saw when you open the app. **Telegram groups:** the feed can also bring in up to 5 Telegram groups or channels read as your own Telegram account, so private groups and alert bots' posts work too. A small **Telegram reader** on Vercel's free tier ([`telegram-proxy/`](telegram-proxy/README.md)) holds the login (made once with `node login.mjs` on your computer) and reads only the groups you listed; the Worker asks it for new messages when the app asks, at most every 20 seconds, so everything stays on free plans. Nothing is ever sent to Telegram, and the calls join the same queue with the group's name as the channel chip and as a tag on the row in that group's own colour ("The" dropped, e.g. **Man Cave**, **Rob's Thoughts**; a coin posted in two groups gets both, one posted in Discord too also gets a **Discord** tag); the same group tags show on Recent calls rows, and the 🚀 alert ends with the group's name; **All · Discord · Telegram** chips show one source at a time, and the Signal scorecard has a **Source** row; a **Telegram** line under the Discord one says if the login ended or Telegram asked it to slow down. **Call score and Best view:** every coin gets a score out of 100 from its first caller's record (30-day win rate and medal), traction (how many callers, the traction channel), a clean launch (bundled %, top 5 wallets, liquidity for its size), whether it has already pumped since the call and how fresh the call is, minus red flags (Walk away or High risk, heavy bundling, top 5 over 45%, a serial-bundler dev, a caller with no record). The bundle part counts the share still held once a check or Dev check has read it (30%+ held is −25), and a Dev check adds +10 for a proven dev or −15 for one whose coins never get anywhere. The queue opens on **Best**, coins scoring 60 or more (adjustable), highest first, each showing its score and why; **All scores** shows everything. The automatic rug check goes to the highest scores first. The points are first guesses to retune from the Signal scorecard. The **Leaderboard** lists every caller the alerts have shown (medal, group, 30-day win rate, calls, 7-day rate, median multiple, the app's own 6-hour average for their calls, last seen), hides callers with fewer than 10 calls by default, and filters the queue to one caller's coins when you tap them. The **Signal scorecard** groups every priced call by the signals it had (bundled %, first caller's win rate, rug verdict, channel, liquidity) and shows the share up and the average return after 1, 6 and 24 hours, once a group has 5 priced calls, so you can see which filters actually paid. **Graduations** (Calls tab): while the app is open it keeps one connection to PumpPortal's free feed and hears every pump.fun coin the moment it graduates to PumpSwap (about one every 1–2 minutes). Three minutes later each is checked, cheapest first: the market check on DexScreener (liquidity $12k+, volume and trades for its age, market cap $60k to $8M), then holders and the rug check (top wallet 5% or less, top 10 at 60% or less, 80+ holders, creator under 10%, mint and freeze closed, not High risk or Walk away). A coin that passes both gets a 🎓 alert (banner, vibration, phone notification) and Check, FOMO, GMGN and **Add to Call queue** buttons; every graduate is listed with where it was cut and why. An on/off switch is remembered, and a **Filters** panel lets you set every number (the wait, liquidity, market cap range, volume, trades, top wallet, top 10, holders, creator, and whether High risk or Walk away cut); mint and freeze must always be closed, and Reset puts the defaults back. **Fees paid at least N SOL** (default 1, after Insentos): with GMGN set up, each graduate past the market check gets one read of GMGN's total fees for the coin, converted to SOL at the current price, and is cut under the floor ("fees 0.3 SOL, under 1"); a bundle rug is bought by the deployer's own wallets with almost no priority fees, so a coin that reached its market cap with under 1 SOL of fees had no real crowd. Without GMGN or a fee figure the row says "fees not read" and nothing is cut; 0 turns it off ([spec](docs/features/grad-fees.md)). **Analyze a wallet** (Calls tab): paste a Solana wallet or a GMGN wallet link. The app reads its latest 100 buys and 100 sells from GMGN, pairs them by token and shows trades per day, average size, median hold (and the share sold within 5 minutes), win rate, average return, market cap at entry, and what copying would cost you at your Fee drag round-trip cost. Claude Sonnet (your Anthropic key) then names its trading style and gives a verdict, **Copyable / Risky / Don't copy**, with reasons. **Paper-copy this wallet** adds it to Copy a wallet below, so you see what following it really earns with your delay. A busy wallet's GMGN history covers only its latest hours, and the report says how many. **Copy gates:** the same report reads GMGN's 7-day, 30-day and all-time record for the wallet and runs four pass / fail gates, each with the number that decided it: **Real record** (not a launcher trading its own coins, not one coin making all the money, 5+ tokens, no wash-trading flag), **Still working** (not −10% this week after +10% all-time, not losing over both 7 and 30 days), **Reachable** (no MEV tag, median entry market cap $30k+, no 10k-follower crowd on small caps, under 100 trades a day, buys of $50+, holds of a minute or more) and **Cuts losses** (under 35% of its tokens down more than 50%). A not-measured gate is never a pass. The verdict names its cause: Do not copy, Hold off, Watch, do not copy, Copy the buys, not the exits, or Copyable at small size, with the record (tokens, win rate, realized, 5× hits), GMGN's tags, Twitter handle and followers, and a size cap of half the wallet's own average buy; Claude's verdict reads the gates too ([spec](docs/features/wallet-gates.md), after GMGN's wallet-analysis skill). **Paper trading** (its own **Paper** tab): a fake-money account that starts at $5,000 (you can change it; **Reset account** starts over) to see what would have worked before risking money; buys take cash out, sells put it back, and the top shows the balance, P&L and cash. **Copy a wallet** (via GMGN): for each wallet you follow you choose how much to follow (a fixed $ per trade, a % of the account, or a % of the wallet's own buy up to a maximum), the entry (**same as the wallet**, an ideal copy at their buy price, or **when the app sees it**, your real delay, with the gap shown) and the exits (**mirror the wallet**: when it sells 40% of its bag the copy sells 40% of what is left; or fixed rules: stop at −40%, half at 2×, the rest at 3×, close after 24 hours); a vanished pool closes at nothing, and buys and sells show within about 5 minutes. And the **AI trader**: Claude Sonnet runs the full check on each Best-list coin (rug check and findings, holder labels, early traders, wallet memory, bundles, callers, optionally the chat), decides once whether to enter with its own size ($50–$200), target and stop and a short thesis, and checks in every 10 minutes to hold, trim or exit; a hard stop at −50%, a 24-hour limit and a daily cap on AI calls (100 by default) are rails it can't override. Each AI entry is also tracked with the fixed exits, so the results table shows whether the AI's judgement beats the rules. Prices are only checked while the app is open; exits found after a gap of 10+ minutes are marked late. Nothing real is ever bought. **Market pulse** (Home, under the wallet): total meme volume over the last 5 minutes, 30 minutes and hour on Solana, Base and BNB (top trending and highest-volume meme pools from GeckoTerminal, majors and stablecoins left out; DexScreener as a fallback without the 30-minute window), a mood of Heating up, Steady or Cooling from how recent volume compares with the hour's pace, the buy/sell split, a trend line of your readings over 24 hours, a **Movers** list of coins whose 5-minute volume is running 3× or more above their hourly pace with buyers ahead, and the same pace reading on your open positions. Refreshes every 2 minutes while open. Volume spikes show attention, not direction. **Scanner** (Calls tab): pulls new launches on Solana, Base and BNB from GeckoTerminal and cuts them in cost order: free cut (3 min to 72 h old, $12k+ liquidity, $40k+ 24h volume, $60k to $8M market cap; coins under 6 hours need volume and trades in proportion to their age, at least $8k and 30 trades), trade cut (150+ trades a day, sells present after 20+ buys in an hour), chain cut (top wallet 5% or less, top 10 at 60% or less, 80+ holders, creator holding under 10%, mint and freeze authority closed, no honeypot). Up to 5 finalists are judged by Claude with your Anthropic key (exit risk, momentum spent, liquidity fit, dev still loaded, crowd, chart shape, worth trading, confidence) and at most one is picked. The card lists every cut coin with its reason. Each pick is logged as a paper trade and priced 1, 6 and 24 hours later, so the scorecard shows whether the picks would have made money. Thresholds come from @savipww's published guide and are unvalidated; no trades are placed. Optional auto-scan every 15 minutes while open. **Thesis drafts:** when a new position appears after a sync (or when you tap **Write thesis** on any check), the app runs the full token check and Claude writes a short first-person thesis for FOMO from those facts only, ending with a Risk line. For coins rated High risk or Walk away the app writes the red flag itself and shows a warning above the draft. Copy, Regenerate and Dismiss; adjustable length limit (default 280) and style notes. FOMO has no write API, so you paste it yourself. **Flow, last hour (Helius):** Solana coins get a read of their actual swaps from the last hour through your Helius key: bought and sold over 5, 30 and 60 minutes, unique buyers vs sellers, the top wallet's share of volume and how many of the 8 biggest buyers are fresh wallets. It labels the coin **Real demand** (20+ buyers, buyers and buy volume at least matching sellers), **Thin**, or **One wallet is the volume** (one wallet 30%+ of the hour, which also becomes a risk finding, high at 50%+). Movers and your open positions in Market pulse get a **Flow** button for the same read. Values use the current price, so they are approximate; busy coins may only be covered for part of the hour. To save Helius credits, the fresh-wallet check on the biggest buyers runs only when you tap **Check fresh wallets**, a re-check of the same coin within 10 minutes reuses its Flow (**Refresh** reads again), and when Helius says your plan is out of credits the app shows **Helius credits used up** and stops calling Helius until you reload it. Paste a contract address (or a DexScreener link). The app pulls the pool from DexScreener and the contract and holder checks from RugCheck (Solana) or GoPlus (EVM chains), then gives a rug-risk score and verdict with findings such as *bundled supply sitting unsold over your head*, *LP in a wallet that can pull it* and *one whale who is the chart*, plus mint/freeze authority, honeypot, taxes, thin liquidity and age. **LP unlock date:** when locked liquidity opens within 60 days (RugCheck lockers on Solana, GoPlus lock end times on EVM chains) Check says *LP unlocks in N days*, or *LP lock has expired* once the date has passed; locks holding under 10% of the coin's liquidity are ignored, and burned or permanently locked LP is never flagged. **Watchlist wallets:** paste wallets you care about in Settings (one per line, with an optional name and a tag: smart, kol, rug or insider). When one of them is among a coin's GMGN top 100 holders or top 100 traders, Check shows a **Your wallets in this coin** block with whether each holds or has sold (a rug-tagged one is a high finding), and Call queue rows get a 👁 tag. It reuses the GMGN data Check already reads, so it costs no extra calls; the list stays on your device and is in the JSON backup. **Creator share:** taken from RugCheck's creator balance, so a creator outside the top 20 holders is still counted (5%+ is a medium finding, 10%+ high). On launchpad pools (pump.fun / PumpSwap, Meteora launch pools, Raydium LaunchLab and similar) the launchpad holds the liquidity, so unlocked LP is not counted as a pull risk there; the largest real wallet is judged against 3% (under 3% shows as a ✓ good sign, 3–5% medium, 5–10% high, 10%+ critical). **Strength:** next to the rug score, a separate Strength 0–100 says how healthy the coin's market is: liquidity (share of market cap and size), volume (24h turnover and the last hour's pace; very high turnover reads as wash trading), holder spread (the largest wallet or linked group, so ten 1.5% wallets that GMGN tags as bundlers, the bundle still held or one operator count as one 15% holder; top 10; holder count) and the total fees traders paid against the volume (GMGN's total fees for coins under a day old, else the app's own estimate after Sample fees; very low fees read as bot volume) and **Wallets** (Solana: the SOL left in the top real holders' wallets, read in one request per check: wallets under 0.1 SOL hold a bag and nothing else, the bundle and burner pattern; 5+ SOL looks like a real buyer; 3+ wallets with nearly the same SOL and supply look like one person), with the red and green flags listed under the parts. Five parts of 20 points. Parts with no data show "not read" and don't count as good. Call queue rows get a small S pill, and the Signal scorecard a Strength row; it doesn't change the call score yet. **Plan:** pick a target market cap and a size (prefilled from Sizing) and it builds a three-trim ladder, a runner and a stop, marking the trim that returns your initial. **Watch:** re-checks every 20 s while the page is open; a trim call fires when a level is hit, a blow-off top or distribution flips the verdict to *Trim into strength*, and a liquidity pull or stop hit says *Walk away*. Tap **Took it** on a trim to record it: exits taken on plan are celebrated and counted in an **Exit discipline** stat. **Creator history (Helius):** for Solana coins, the creator wallet's last 500 transactions are read for the coins it launched before (up to 20), each is looked up on DexScreener and called Alive, Quiet (volume under $500 a day) or Dead (no pool or under $1k liquidity); launches under 6 hours old aren't judged. The block shows "7 of 8 earlier launches dead" with the list and a Check button on each (with GMGN, also each coin's peak, the best peak and a verdict); dead coins on their own are not a finding, since most coins fade. **Dev track record** (GMGN, on demand): a **Deep dev check** button on the Check tab and a **Dev check** button on each Call queue row show how far the dev's earlier coins got (best and median peak market cap, how many passed $100k and $1M, the most holders on one coin, total volume and global fees, the top 5 coins), with a verdict: **Proven dev** (a coin past $1M, or two past $100k), **Never gets anywhere** (5+ launches over 6 hours old, none past $50k; a high finding) or Mixed, and a **bundle verdict** read with it: bundle sold, bundle held (30%+ still held is bad), **team launch** (bundled, proven dev) or **extraction pattern** (bundled, a dev whose coins never get anywhere). Up to 6 GMGN requests, remembered for an hour per dev wallet; a queue row shows a one-line summary that opens the full record on the Check tab ([spec](docs/features/dev-record.md)). Dead means the market is gone, not necessarily a rug (there is no launch price to measure a drop), and a creator who uses a fresh wallet per coin shows no history, which the block says is not the same as clean. **Turnover** (volume ÷ market cap): every Call queue row shows `vol $45k · 2.3× mcap` (green at 2× and up, red under 1×), a **Min turnover** filter and a **Hide volume < mcap** box hide coins whose supply hasn't changed hands (volume under market cap is mostly buys and few sells, the bundle pattern; credit @bigwarzeth), the Graduations filters get a **Volume at least N× mcap** field, the Check tab shows the ratio under the Volume tile and raises a medium finding when a coin at least an hour old has 24h volume under its market cap (skipped when the creator holds half), with a good note at 2× and up ([spec](docs/features/turnover.md)). **CrawlScan** (crawlscan.fun, on demand, through the Worker): a **Run CrawlScan** button on the Check tab for Solana coins and a **CrawlScan** button on each Call queue row run crawlscan.fun's own scan (about 10 seconds on their servers, remembered 30 minutes): a 0–100 from who really operates the top wallets and what their exit would do to the price (35), virgin wallets (25), supply received by transfer (20), snipers (10) and concentration (10), with a CLEAN / OK / RISKY / DANGER band, the headline, and the biggest operators (wallets, share of float, holding or sold). DANGER is a high finding, RISKY medium, and CrawlScan's dump impact speaks for the operator finding when it is the larger estimate. Queue rows get a `CS 59 · RISKY` tag that opens the block. Never run automatically ([spec](docs/features/crawlscan.md)). **Bundle check** (isitbundled.com, free, no key): for Solana coins, how much supply was bought together at launch, by how many wallets, the share bought in the first second, the dev's buy, whether a bundling tool (Proxima, Sumo) made it, and the dev's launches in the last 7 days with how many were bundled; 30%+ bundled is a high finding, 15%+ medium, and a dev who bundled every one of 3+ recent launches is high. Coins it hasn't scanned say so instead of reading as clean. In the Call queue one request covers 100 coins: each row gets a bundle tag, coins over 40% bundled skip the automatic rug check, and a Max bundled % filter hides the rest. **GMGN (through the Worker):** with a `GMGN_API_KEY` secret on the Discord feed Worker, the Check tab shows **Early traders**, how many of the first 10 wallets in have sold and how much profit they took (8 of 10 sold is a finding), and the Dev dossier uses GMGN's list of the creator's launches instead of Helius. The key stays in the Worker; only eight read endpoints are forwarded, never trading. GMGN sometimes bans Cloudflare's shared addresses, so an optional **GMGN API key** in Settings → Advanced (stored only on your device, read-only) lets the app ask GMGN directly when the Worker is refused. **Holder labels (GMGN):** the same GMGN connection reads GMGN's own labels on the top 100 holders: the share of supply held by bundlers, insiders (GMGN's "rat traders"), snipers and dev wallets (30%+ is a high finding, 15%+ medium), and how many smart-money and KOL wallets hold the coin and whether they have sold most of their bag (3 or more smart wallets with most of them selling is a medium finding). No Helius credits used; shares are floors since only the top 100 are read. **Wallet memory (GMGN):** when a priced Call queue coin rugs (−80%) or runs (3×), the app asks GMGN once who took profit on it and remembers the real wallets that made $500+ and were in by the time the call was seen (on this device, up to 5,000 wallets). A wallet that profited on 2+ rugs is a rug wallet, on 2+ runners a runner wallet, on both a bot. The Check tab's **Wallet memory** block flags known wallets among a coin's top holders and traders (2+ rug wallets is a high finding), and the best queue coins get −25 for 2+ rug wallets or +10 for 2+ runner wallets on their call score. It needs a couple of weeks of coins to be useful. **What people are saying:** tap **Read the chat** on the Check tab (or **Chatter** on a Call queue row) and the Discord feed Worker searches your on chain feed channel (`CHATTER_CHANNEL`) for the coin's address and $ticker over the last 24 hours, the messages are sorted by the group code at the start of each poster's name, and Claude Haiku sums it up with your Anthropic key (about 0.2¢ a tap): the mood, a line per group, the claims people make and any red flags they mention. Nothing is read until you tap and nothing is stored. **Price chart (GMGN):** a collapsed **Chart** panel on the Check tab embeds GMGN's live candle chart for the coin (1s, 1m, 5m, 15m and 1h buttons, no key needed, loaded only when you open it), with an **Open on GMGN** link if the embed is blank. **Open in FOMO:** every coin with a known chain FOMO trades (Solana, Base, BNB, Ethereum, Monad, Hyperliquid, Robinhood, Arc) gets a FOMO button that opens its fomo.family page, which the FOMO app opens on a phone; it is on the Check tab, Call queue rows, Recent calls, Scanner picks, Paper trades and Market pulse Movers. Calls-tab coins also get a **GMGN** button (gmgn.ai's page for the coin, which the GMGN app opens if installed) on chains GMGN trades. ### How synced trades are built

Each swap that trades SOL (or wrapped SOL) for a token counts as a buy or a sell of that token. Buys of the same token are averaged together. A trade **closes** once the position is fully sold:

- cost = all SOL put in
- proceeds = all SOL taken out
- fees are included because the app uses the wallet's real SOL balance change.

Not counted:

- token↔token swaps and swaps with several tokens
- sells of tokens bought before the synced history starts.

### CSV format

```
token,openedAt,closedAt,cost,proceeds,notes
BONK,2026-09-30T14:00:00Z,2026-09-30T16:30:00Z,0.5,0.82,breakout
```

`cost` and `proceeds` are in SOL.

## Tests

![Tests](https://github.com/0xDP1/Fomo-tracker/actions/workflows/tests.yml/badge.svg)

```sh
npm ci                               # once: ESLint, TypeScript (type check only), Playwright, Chart.js. The app itself has no build step.
npm run check                        # lint + type check + unit and Worker tests (what GitHub runs on every push)
npx playwright install chromium      # once, for the browser tests
npm run e2e                          # every browser test against a local copy of the app
node tests/e2e/run.js calls alerts   # only the named ones
```

The browser tests mock every outside service (DexScreener, RugCheck, Helius, Anthropic, the Discord feed, isitbundled.com), so they need no keys or network. Screenshots go to `tests/e2e/out/` (ignored by git). Chart.js is served from `node_modules` when installed, otherwise a stub stands in. The type check covers the shared logic modules (`jsconfig.json`); the page scripts are checked by ESLint.

After changing `calls.js` or anything in `worker/`, rebuild the dashboard copy of the Worker with `node worker/bundle.js` (a test fails if you forget).
