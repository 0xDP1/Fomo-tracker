    Position sizing

    Inputs

    Suggested size

    How it works. Risk-based: size = balance × risk% ÷ stop%, so if your stop hits you lose exactly your risk%. Kelly: f = W − (1−W) ÷ R, where W is your win rate and R is avg win % ÷ avg loss % from your own trades. Full Kelly is very volatile; most traders use ¼–½. If Kelly ≤ 0, your recent trades show no edge, so size down. This is math on your history, not financial advice.

    Settings

    Fills in the URL and header. Paste your fapi_… key into "Lookup API key" and save. A fapi_ key with the URL left blank uses fomoapi.io automatically.

    If you set a lookup API, unknown usernames are resolved automatically: the app takes the Solana address from the response. Otherwise you paste the address once per username.

    FOMO connection check

    Tests each fomoapi.io endpoint and shows what came back. Use it if the balance, PnL or trades aren't updating.
